题目内容

Java 中，以下关于 String、StringBuilder 与 StringBuffer 的说法，哪一项是正确的？

选项
A String 是可变字符串，适合频繁拼接
B StringBuilder 线程安全，StringBuffer 非线程安全
C StringBuffer 线程安全，StringBuilder 非线程安全但性能更高
D 三者底层存储结构完全相同
参考答案

C

解析

String是不可变对象；StringBuilder非线程安全、性能最高；StringBuffer对其方法加锁，线程安全。故选C。
