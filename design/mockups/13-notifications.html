通知类型枚举与跳转规则

列表项标签文案取自 TYPE_META，未命中时回落 DEFAULT_META（系统通知 / NotificationsOutline / bg-neutral-100 / tag default）。 跳转由 resolveNotificationRoute(notif) 统一解析：link 优先，缺失时按 type + relatedId 兜底；返回空则整条通知不可点、不渲染「查看详情」。

分页

v-if="pagination.itemCount > pagination.pageSize"，容器 flex justify-center mt-6；pageSize 固定 20， 无每页条数切换、无快速跳页、无「共 N 条」文案。上面主形态仅 8 条，因此不渲染分页。

加载态

首次进入 / 切 Tab / 翻页均 loading = true，由 n-spin 以遮罩形式覆盖整个列表区； 代码未使用 SkeletonList，加载中不区分「已有数据」。
