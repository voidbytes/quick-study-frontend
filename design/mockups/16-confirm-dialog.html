参数清单

ConfirmActionOptions = Partial<Pick<DialogOptions, 'title' | 'content' | 'positiveText' | 'negativeText' | 'onPositiveClick'>>，全部可选。
参数类型默认值说明
titlestring confirm: '确认操作' / confirmDanger: '确认删除' 弹窗标题
contentstring confirm: '确定要执行此操作吗？' / confirmDanger: '此操作不可撤销，确定继续吗？' 正文描述
positiveTextstring confirm: '确认' / confirmDanger: '删除' 确认按钮文案（confirmDanger 恒为红色 error 按钮）
negativeTextstring '取消' 取消按钮文案
onPositiveClick() => void — 点击确认的回调，支持 async（await 返回 Promise）
positiveButtonProps固定注入 { type: 'error' }（仅 confirmDanger） confirmDanger 预设，确认按钮呈红色
style固定注入 'border-radius: 16px;' confirm / confirmDanger 统一注入的容器圆角

交互逻辑

调用形态：const { confirm, confirmDanger } = useConfirm()。
方法Naive UI 底层行为
confirm(opts) dialog.warning 普通确认，图标 warning 色、主按钮品牌色；点击「取消」或遮罩关闭，无回调
confirmDanger(opts) dialog.error 危险操作确认，图标 error 色、确认按钮红色；点击确认执行 onPositiveClick，成功后通常 message.success 并刷新列表
