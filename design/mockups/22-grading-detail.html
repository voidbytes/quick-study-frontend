题干
简述 Java 中接口（interface）与抽象类（abstract class）的主要区别。
用户答案
接口只能定义抽象方法和常量，不能包含方法体；抽象类可以有方法实现和构造方法；类可实现多个接口，但只能继承一个抽象类。
参考答案
1. 接口不能有构造方法，抽象类可以有。2. 接口方法默认 abstract，抽象类可有具体实现。3. 类可实现多个接口，但只能继承一个抽象类。
得分
组合式 API ✓ setup ✓ 响应式 ✓ 多实现 ✗
要点齐全，仅缺少对“单继承 vs 多实现”的对比说明，建议得分 9/10。
