实现要点

  • 生成请求：POST /admin/invite-codes body { count, maxUses, validDays|expireAt, grantRole, remark }，返回明文码数组。
  • 数量上限 50（invite-code.max-generate-count）；前端 n-input-number 的 max 与后端配置保持一致。
  • grantRole = ADMIN 时备注必填，前端在切换单选时动态加 required，后端同样校验（95202）。
  • 结果弹窗的「复制全部」输出换行分隔的无连字符原始码，「下载 .txt」同理。
  • 使用记录 IP 脱敏由后端返回已处理字符串（保留前两段），前端不做二次处理。
  • 结果弹窗关闭时触发列表刷新（emit('success') → loadList()）。
