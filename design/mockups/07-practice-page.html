关于 Java 集合框架，以下说法正确的有？
A
ArrayList 底层基于数组实现
B
LinkedList 同时实现了 List 和 Deque 接口
C
HashMap 是线程安全的
D
TreeMap 基于红黑树实现
E
HashSet 底层使用 HashMap
回答正确！ 本题正确答案为 B、D，用时 42 秒。
解析
LinkedList 同时实现了 List 与 Deque 接口，因此既可以作为列表按索引访问，也可以作为双端队列使用；TreeMap 内部基于红黑树（Red-Black Tree）实现，能够保证键有序并维持 O(log n) 的查找、插入与删除复杂度。需要注意 HashMap 并非线程安全的，并发场景下应使用 ConcurrentHashMap 或通过 Collections.synchronizedMap 包装。
